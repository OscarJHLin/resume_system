# 需求规格（PRD）— 拼履

- as_of: 2026-09-23
- status: Designed（地基阶段，尚未实现可观察能力）
- 权威性: 产品范围以本文为准；实现不得静默扩大或缩小 MVP
- 产品决策: D1–D4 **已锁定**（见 §7）

## 1. 目标与价值

**一句话**：把可复用的能力/项目/实习等**结构化模块**，按用户维护的**标签**检索后拖入简历版式，再导出 DOCX。

**要解决的痛点**：

- 同一段项目/技能文案在多份简历间复制粘贴，易不一致、难检索。
- 换投递方向时缺少「打标签 → 检索模块库 → 组装 → 导出」闭环。
- 版式/字段排版与内容混在一起，换模板时要整篇重排。

**成功标准（MVP 可观察）**：

1. 用户能维护一份个人资料（基本信息 + 教育背景）。
2. 用户能为模块维护多标签，并在内容库中按大类/标签检索，再拖入简历对应区块。
3. 放入区块后，**各结构化字段**按唯一 MVP 模板的**分字段**排版规则呈现（非整段混排 HTML）。
4. 用户能导出一份可读的 `.docx` 文件。

## 2. 用户与场景

| 角色 | 描述 | 主要目标 |
|---|---|---|
| 求职者（主用户） | 有多段可复用经历，靠标签组织后组装不同简历 | 快速组装、导出投递稿 |
| 未来：模板作者 | MVP 不做独立角色 | 配置版式（延后） |

### 主场景（正常链）

1. 打开工作台：侧栏为**内容库**，主区为**简历文档编辑器**。
2. 在内容库按大类（技术能力 / 项目经历 / 实习经历）与**标签**过滤/搜索模块。
3. **拖拽**模块到简历对应 section drop zone。
4. 系统将模块**快照**写入该简历；再按模板的分字段规则渲染（标题、副标题/担任的职责、项目类型、时间、正文等）。
5. 调整顺序（MVP：拖入顺序即顺序；细粒度排序可后续加强）。
6. 点击导出 DOCX，下载文件。

### 拒绝链

- 拖到**不匹配大类**的 section：拒绝落入，提示「该模块类型不能放入此区块」。
- 内容库为空或无匹配：展示空态，不阻断编辑已有内容。
- 个人资料未填必填项时仍可组装；导出时对缺失字段按模板规则留空或占位。

### 失败 / 恢复链

- 导出失败：保留当前简历草稿，展示错误信息，可重试。
- 服务/本地存储不可用：提示并阻止静默丢数据。

## 3. 领域名词

| 名词 | 含义 |
|---|---|
| Profile（个人资料） | 基本信息 + 教育背景；相对固定，写入每份简历页眉/教育区 |
| ContentModule（内容模块） | 可复用单元；**结构化字段** + 纯文本正文 + 大类 + 标签 |
| Category（大类） | `skill` / `project` / `internship`（MVP）；后续可加 `award` |
| Tag | 用户为模块维护的检索标签；**检索主模型**（无独立 JD 实体） |
| ResumeDocument | 一份简历：绑定 profile + 各 section 的 **ModuleSnapshot** 列表与顺序 |
| ModuleSnapshot | 拖入时从 ContentModule **深拷贝**的字段副本；此后与库内原文脱钩 |
| Template | 版式 + 装饰 + **每个字段**的排版规则；MVP **仅 1 套** |
| Section | 简历区块：basic / education / skills / projects / internships / awards |
| ResumeIR | 模板映射后的中间表示，供预览与 DOCX 共用 |

## 4. 简历区块与内容来源

| Section | 来源 | MVP |
|---|---|---|
| 基本信息 | Profile | 有 |
| 教育背景 | Profile | 有 |
| 技术能力 | ContentModule (`skill`) | 有，拖入 → 快照 |
| 项目经历 | ContentModule (`project`) | 有，拖入 → 快照 |
| 实习经历 | ContentModule (`internship`) | 有，拖入 → 快照 |
| 获奖与证书 | ContentModule (`award`) | **延后**（结构预留） |

### 模块结构化字段（强制分离）

内容与排版解耦的前提是字段分离。库内模块与快照均包含：

| 字段 | 含义 | 存储 |
|---|---|---|
| `title` | 标题 | 纯文本 |
| `subtitle` | 副标题 / 担任的职责 | 纯文本，可空 |
| `projectType` | 项目类型 | 纯文本，可空 |
| `timeRange` | 时间范围 | 纯文本（展示格式由**模板**决定） |
| `body` | 正文 | **纯文本**（保留换行；非 Markdown / 非 HTML） |
| `category` | 大类 | 枚举 |
| `tags` | 标签列表 | 字符串数组；用户撰写后可加多个标签 |

技能模块可用字段子集（如 `title` + `body` + `tags`），同一模型用可选性表达；**不得**把标题/时间/正文糊进单一富文本 blob。

模板必须为各字段定义独立格式规则（如 title 加粗/字号、timeRange 展示形态、body 正文字号等），再映射进 ResumeIR / DOCX。

## 5. MVP 范围

### 包含

- 个人资料 CRUD + 复制（基本信息、教育条目列表；复制生成新卡「姓名（副本）」）
- 内容库 CRUD；模块**多标签**维护；按大类 / 标签 / 关键字检索
- 拖入时 **SNAPSHOT** 写入简历；单一简历草稿组装
- 单一内置模板的**分字段**映射与预览
- DOCX 导出（仅 DOCX）
- 工作台布局（编辑区 + 内容库侧栏）
- 运行时：本机 **Web + API + SQLite** 原型（见 D3）

### 不包含（Non-goals / 延后）

- **独立目标岗位 / JD 实体**、JD 导入、基于 JD 的自动匹配（检索只靠用户标签）
- 关联推荐 / 语义联想检索（可后做增强；MVP 仅标签 CRUD + 标签过滤）
- 拖入后「从库刷新快照」（可选后续；MVP 无自动回写、无实时同步）
- PDF 导出；多模板市场 / 可视化模板设计器
- 点击添加（click-to-add）
- 多用户账号、云同步、权限体系
- Markdown / 富文本正文；完整 Word 级排版引擎
- 获奖证书完整流程（仅数据模型预留）
- 移动端优先；**可安装桌面分发包**（长期目标，见 ADR-0004，非本阶段交付）

### 红线

- 不在 MVP 把内容与版式硬编码缠死在编辑器 HTML 里（须经 Template → IR）。
- 不把多字段揉成单一 HTML/Markdown 再靠样式猜测拆分。
- 不把 DOCX 做成「整页 HTML 截图式」伪导出。
- 不引入多租户/账号系统阻塞本地可跑通。
- 不实现 JD 实体「先做着再说」。

## 6. 不变量

1. **拖入即快照（D1）**：`SectionPlacement` 持久化完整 `ModuleSnapshot`；库内后续编辑**不**自动改已组简历。`sourceModuleId` 仅溯源，非实时外键同步。
2. **大类 ↔ section 兼容矩阵**必须强制（见 `docs/contracts/content-library.md`）。
3. **Profile 与 Module 分离**：基本信息/教育不进入可拖拽模块库（MVP）。
4. **结构化字段 + 纯文本 body（D2）**：模板与导出按字段消费，不得依赖正文内嵌标记做主排版。
5. **检索靠标签（D4）**：无 TargetJob/JD 表或 API。
6. **导出输入是 ResumeIR**，不是 TipTap HTML 直出 docx。
7. MVP **有且仅有一套**内置 Template id（`default-v1`）。

## 7. 已锁定决策（2026-09-23 用户确认）

| ID | 决策 | 说明 |
|---|---|---|
| **D1** | **SNAPSHOT** | 拖入 section 时深拷贝字段快照进简历；不与库内模块实时联动。 |
| **D2** | **纯文本 + 结构化字段** | `body` 为纯文本；title/subtitle/projectType/timeRange/tags/category 等字段分离；模板按字段定义样式。 |
| **D3** | **原型本地 Web；长期桌面** | 近期：Vite/React + Fastify + SQLite。长期：Win/Mac 可安装应用 + 本地持久化；领域模型与 SQLite 应可迁入桌面壳（见 [ADR-0004](./adr/0004-desktop-path.md)，首选 Tauri）。 |
| **D4** | **无 JD 实体；标签检索** | 不做目标岗位/JD；用户为经历打多标签，侧栏按标签搜索/过滤。关联搜索属未来增强。 |

以上决策已闭合；实现与合同以本表为准。变更须先改本文与相关 ADR，再改代码。
